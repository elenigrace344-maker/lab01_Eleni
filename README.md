# Lab 2 – Python Input Application

This project implements keyboard and file input operations in Python, following the lab requirements.

## Features

### Requirement 1 – Console Input
- Read a sequence of numbers from the keyboard.
- Read a 2D array of numbers (dimensions provided by the user).
- Display the results clearly.

### Requirement 2 – File Input
- Read a filename from the keyboard.
- Load a sequence of numbers from the file.
- Handle missing files gracefully.

## How to Run
```bash
python console_input.py
python file_input.py
